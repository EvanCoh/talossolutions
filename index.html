About Talos Solutions

We build the integration layer around Norwegian real estate: public registers, broker systems, and AML reporting. The work is serverless where that fits — Azure Functions, Key Vault, test and prod — so property software can call Skatteetaten, Altinn and Økokrim without owning that complexity.

Typical buyers are eiendomsmeglere, proptech vendors, and product teams that need Maskinporten, matrikkel lookups, or an embeddable app inside Core, Webmegler or Vitec.

Norwegian real estate work

Production systems for brokers and the platforms they already run — cadastral data, tax value, and suspicious-activity reporting — delivered as APIs and serverless services.

Property tax value

Serverless proxy to Skatteetaten Formuesverdi for eiendomsmegler opplysningsplikt. Matrikkel (kommune, gård, bruk, feste, seksjon) and boligselskap, scoped per organisation.

AML reporting

Økokrim FIU / MFR integration so real-estate firms can create, validate and submit reports from their own workflow instead of a separate portal.

Serverless integration

Azure Functions, Maskinporten tokens, Key Vault and observability (Application Insights / Datadog). Test and production, multi-tenant consumers, no secrets in the app.

Integrations

We connect Norwegian public APIs and the broker systems used in the market.

Altinn

Digital reporting and public-sector services. Organisation-scoped access, forms, and obligations that sit next to the broker workflow.

Maskinporten

Machine-to-machine tokens for Skatteetaten, Altinn, Økokrim and other Norwegian APIs. JWK in Key Vault, separate test and prod.

Core

Visma Real Estate Core — embeddable integrators, launch URLs and APIs inside the broker desktop, including marketing and compliance flows.

Webmegler

Integrations with Webmegler so listing data, valuation and reporting stay in the system many Norwegian offices already use.

Vitec

Vitec Next and related Nordic broker software — connecting the office system to public registers, tax value and AML APIs.
